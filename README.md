# GNOME Application Development Guide

Beginner-to-advanced reference for building GNOME apps (GJS primary, Python and Rust companions).

- Source: `chapters/*.md` (edit these)
- Build: `./build.sh` → `build/GnomeDevGuide.pdf` (+ `.html`)
- Build deps: `python3 -m venv .venv && .venv/bin/pip install markdown weasyprint pygments`
